# Brand direction

## Working name

**Ventru.net**

Short, premium, ownable, and trust-coded. It does not sound like another AI directory; it sounds like a verification network agents would rely on.

## Category language

- agent-native internet
- Web 4.0
- agent-readable business standard
- machine-readable commerce layer
- action layer for the internet

## Core positioning

Ventru.net is the trust layer for the agent-native internet.

The old web was built for people to click through pages. The next web is built for agents to read, compare, trust, and act.

Good positioning lines:

- The trust layer for the agent-native internet.
- Turn any website into infrastructure AI agents can use.
- Web 4.0 is not prettier pages. It is data, trust, and actions.
- Be discoverable, comparable, quotable, and bookable by agents.

## Human search experience

Ventru.net still needs a familiar search box. Humans trust what they can explore. The homepage should let a normal business owner search the index like Google, click a provider, and see the agent.json/llms.txt files behind it. That proves this is not just abstract protocol talk; it is a real index with real listings.


## Names worth checking for domains

### Current top tier

1. **Ventru.net** — best current brand: premium, ownable, trust/verification-coded, and less generic than Ventru.
2. **ActionWeb** — strongest if the pitch becomes "agents do things, not searches."
3. **AgentRank** — easiest to sell to local businesses as SEO for agents.
4. **MachineWeb** — serious and broad, good if we want more protocol gravity.
5. **Web4 Index** — owns the Web 4.0 narrative, but slightly more speculative.
6. **TrustGraph** — best if verification/reputation becomes the defensible moat.

## My read

**Ventru.net** is a better brand than Ventru if the goal is to look premium and defensible. Ventru explains the category; Ventru.net can own the company. **Action Capsule** should become the proprietary product primitive. **AgentRank** remains the merchant-facing score: "your AgentRank is 82."
